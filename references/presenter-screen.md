# Presenter + screen mode

Use this when narration or a talking head leads and the screen recording proves or demonstrates the spoken points.

1. Map the source speech into a concise arc: opening, problem, walkthrough, value, close. Transcribe only as much as needed to avoid cutting a sentence or changing its meaning. Mark exact source in/out times and likely breath points.
2. Select screen moments by semantic match to the narration, not merely by chronological order. Give each insert a specific purpose, such as research, scripting, choosing a visual style, or showing the output. Crop so the relevant UI is legible on the target aspect ratio.
3. Keep the presenter visible when useful: full-frame for personal connection, then picture-in-picture or a clean side panel while demonstrating. Screen inserts should last long enough to understand the action. Avoid covering important UI or the presenter's face with text.
4. Use short keyword labels rather than a paragraph of decorative copy. If the user asks for subtitles, add accurate speech-timed captions as a separate layer; keyword labels do not count as subtitles.
5. Build voice audio from the same source windows as the presenter video. Normalize the resulting continuous track to the target timeline length without stretching the speech. Match visual cut points to its words. Silence detection should find only real pauses, not multi-second gaps caused by clip switching.
6. Preview and verify at every hard cut, especially the first screen insert and the return to presenter. After export, inspect the encoded audio at those timestamps.

For the Brandflow pilot, the approved treatment is 60 seconds, 9:16, a simple Inter/off-white/muted-gold style, original presenter voice, and selectively cropped product-screen inserts. This is an example, not a mandatory template for all videos.
