# Multi-scene mode

Use this when the clip sequence, rather than one continuous speaker, carries the story.

1. Inventory candidate scenes with duration, aspect ratio, usable audio, and the clearest visible action. Identify the hook, escalation or demonstration, payoff, and close. If the footage does not support a claimed payoff, don't create one with captions.
2. Write a compact beat map with source clip/in/out, timeline start, visual purpose, audio source, and overlay text for each scene. Keep source continuity when it matters (direction of motion, character positions, props, time of day).
3. Cut on action or an audio beat where possible. Use hard cuts by default; add a transition only when it clarifies a change of place, time, or idea. Avoid stacking many effects simply because the reference video uses them.
4. If there is dialogue or a voiceover, preserve intelligibility and build a continuous main speech track from the kept windows. Source ambience may bridge a cut if it helps continuity. Music and SFX require user intent or a clearly beneficial suggestion; do not let them mask speech.
5. Use the shared restrained visual style: minimal sans-serif labels, consistent safe margins, clear hierarchy, no flourishes. Adapt color to the footage but maintain contrast.
6. Preview beginning, midpoint, end, and every scene boundary. After export, verify the encoded MP4 and review for frozen/black frames, timing jumps, lost voice, missing props, or unexpected text.

Deliver only the MP4 unless the user asks for the editable project or supporting assets.
